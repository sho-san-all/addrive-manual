## 概要

AdDriveは、広告代理店向けの案件・媒体管理SaaSです。案件（キャンペーン）の登録、数値の確認・分析、月次レポートの作成をひとつの環境で行います。

## 使い始める前に

1. **ログインする** → [ログインとクライアントビュー閲覧](/docs/start/login)（GWSグループへの追加依頼＋Googleアカウントでログイン）
2. **自分の名前・クライアント名が出るようにする** → [自分の名前やクライアント名が出てこないとき（初期設定）](/docs/start/my-page-setup)

新しくAdDriveを使い始める人は、上記の2ページを先に済ませてください。

## どの画面で何ができるか

| 画面 | できること |
| --- | --- |
| マイページ（`my-drive/<自分のID>`） | 自分の担当案件をクライアントごと・媒体ごとに数値で確認 |
| 担当者横断ビュー（`my-drive/all`） | 全担当者の広告状況を横断で確認 |
| クライアント別ページ一覧（`allclient`） | クライアントごとの社内ビュー・クライアントビューへのリンク一覧 |
| 社内ビュー（`client-drive/<クライアントID>`） | クライアント単位の実績確認。動作が軽く、社内での数値確認・スクショはこちらを使う |
| キャンペーン登録・編集（`campaigns_register`） | 案件情報の登録・編集。すべてのページの集計の元になる |
| キャンペーン登録用 選択項目（`settings/campaign-select-settings`） | 担当者名・クライアント名・フロント名などの選択肢を管理 |
| メンバー設定（`settings/unit-score`） | マイページID・Unit所属の新規登録 |
| マーケット分析（`market-ad-insights`） | クライアント名を伏せた市場分析データ |
| ツール ＞ ADエキスパちゃん | 実績数値をAIが参照しながら課題を言語化する壁打ちツール |

詳しい使い方は、それぞれの機能ページを参照してください。
